# Chrome Web Store listing

## Product details

- Name: JobCheck — Job Offer Safety
- Category: Productivity
- Language: English
- Visibility: Public

## Short description

Check suspicious job messages, sender emails and listing URLs for common warning signs before you trust them.

## Detailed description

JobCheck helps students and job seekers examine suspicious job offers using clear, transparent rules.

Paste a job message, sender email or listing URL to receive a warning-signal score, explanations and practical verification steps. You can also select job text on a webpage, right-click and open it directly in JobCheck.

JobCheck performs its analysis locally in your browser. It does not contact employers, open submitted links or send the material to an external analysis service. Reports are saved only when you choose to save them, and saved reports remain in the extension's browser storage until you clear them.

JobCheck is an educational safety aid, not a verified fraud detector. False alarms and missed scams are possible. Always verify an employer independently before paying money, sharing identity documents or acting on an offer.

## Single purpose

Help users identify and understand common warning signs in job offers and provide safer verification steps.

## Permission justification

`contextMenus` is used only to add “Check selected text with JobCheck” to the browser's right-click menu. The selected text is passed to JobCheck's local extension page after the user explicitly chooses that menu item.

## Data-use declaration

JobCheck does not sell data, use data for advertising, or transmit submitted content to an external service. User-entered content is processed locally. A report is stored locally only when the user selects the save option, and the user can clear saved history.
